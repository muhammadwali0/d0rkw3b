# Changelog

## 1.0.0

- Installable src-layout package with `d0rkw3b` and `python -m d0rkw3b` entry points.
- Declarative registry preserving all 425 legacy links and source provenance.
- Automatic target detection, validation, central encoding and category filters.
- Deterministic JSON, CSV, Markdown and text output; interactive terminal prompt.
- Explicit single-provider browser opening and Tor isolation from browser launch.
- Honest unverified metadata and disabled retention of questionable endpoints.
- Removed bundled API key, copied image-search tracking parameters and unused
  requests dependency; corrected X year query end boundaries.
- Offline regression tests, packaging checks, contribution and security guidance.
