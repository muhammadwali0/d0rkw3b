# Community conduct

Be respectful, constructive and considerate. Discuss code and evidence rather
than attacking people. Harassment, discrimination, threats, doxxing, and posting
private target data or credentials are not acceptable.

Maintainers may edit or remove contributions, close discussions, or restrict
participation to protect the community. Report problems through available
repository moderation/reporting controls. Avoid repeating private information in
public reports. This applies to project issues, pull requests and discussions.
