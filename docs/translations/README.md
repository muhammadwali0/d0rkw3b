# Community translations

English pages in `docs/` are canonical. Contributors may add
`docs/translations/<language-tag>/` with translated pages and an index linking to
the matching English sources. Use an appropriate BCP 47 language tag, preserve
command names/code, and record the source commit and reviewer/date for each page.
Do not invent native support, verification claims or localized behavior. Ask a
fluent reviewer to assess accuracy and accessibility. Mark incomplete translations
clearly and link back to English for missing pages. No translations are bundled
yet. CLI localization remains future work.
